## 結論

❌ **不採用** AWS の EC2 は使わない（2026-10-17 決定）。

- 既存アカウントの無料枠は 2017-02 に終了済み。EC2 に常時無料の枠は無い
- 最小クラス（`nano`・0.5 GB）はメモリが小さく実用にならない。実用的な `t3.micro` は月 2,100 円ほど（概算・未確認）かかる
- 別アカウントは作らない
- 他社の常時無料枠（Google Cloud の `e2-micro`、Oracle Cloud の Arm VM）は候補として残す。現行条件は未確認
